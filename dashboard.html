Misma wifi en móvil y PS5. En F1 > Ajustes > Telemetría: UDP Telemetry On, UDP Broadcast Mode Off, UDP IP Address = la IP de arriba, UDP Port 20777, UDP Send Rate 20-60 Hz, UDP Format 2026. Si el móvil cambia de IP, ponla de nuevo.
