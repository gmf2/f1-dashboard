Sin conexión
Sin conexión. Esta página web no recibe datos del juego: el juego envía UDP y una web en GitHub Pages no puede recibirlo. Para el modo En directo hace falta un programa receptor en tu PC (o un móvil/tablet en la misma red) que lea la telemetría del juego. Esta versión aún no está conectada a ninguna partida y no inventa datos. Pulsa «Probar demo» para ver las pantallas con datos de ejemplo.
